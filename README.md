# MythTech
The MythTech mod, Featuring Technology and RPG on the same package.

<h1>The mod is being developed yet, so please be patient.</h1>

There is barely any mod nowadays that focus on two completely different branches, like Adventure and Technology, and this forces players to run big modpacks, that not every PC can handle.


Due to this reason, we created an amazing modpack with plenty of content. Giant cyclops and rotors on the same mod? YES! With this modpack, you can have a good performance X content with only a minimal decent PC.
